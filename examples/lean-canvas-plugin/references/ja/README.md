## よくある質問

**Q: Lean Canvas と Business Model Canvas の違いは？**  
A: Lean Canvas はスタートアップ向けにシンプル化され、Business Model Canvas は大企業向けにより詳細です。

**Q: どのくらいの頻度で見直す？**  
A: 3ヶ月ごと、または大きな変更が生じたときに見直します。
