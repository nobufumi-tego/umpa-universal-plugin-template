# プラグイン名 学習ガイド

このフォルダは、プラグイン名の日本語学習資料です。

## 推奨学習パス

### 初級者向け（初めての方）

1. **01-concept.md** - 背景・なぜこれが必要か
2. **02-step-by-step.md** - 実装方法・実践ガイド

このパスで、基本的な理解と実装方法を習得できます。

### 中級者向け（実運用・改善）

1. **01-concept.md**（復習）
2. **03-case-studies.md**（失敗事例から学ぶ）
3. **02-step-by-step.md**（改善実装）

このパスで、実装後の改善方法と失敗パターンを理解できます。

### 上級者向け（カスタマイズ・応用）

1. **04-advanced.md**（応用テクニック）
2. **03-case-studies.md**（パターン認識）

このパスで、より高度な活用方法を習得できます。

## よくある質問

**Q: どのファイルから始めるべき？**  
A: 初めての方は 01-concept.md からスタートしてください。背景を理解してから 02-step-by-step.md で実装します。

**Q: すべてのファイルを読む必要がある？**  
A: いいえ。あなたのレベルと目的に応じて、推奨学習パスから選んでください。

**Q: 実装中に分からないことがあったら？**  
A: 02-step-by-step.md の「よくある間違い」セクションを確認してください。
